# 📚 STUDIUL INDIVIDUAL
IntelliJ IDEA • Git • GitHub

## Descrierea proiectului:
Acest repository a fost creat în cadrul studiului individual cu scopul de a învăța și de a aplica practic cunoștințele despre utilizarea aplicației IntelliJ IDEA, sistemul de versionare Git și platforma GitHub.

Realizarea studiului s-a bazat pe mai multe surse de informare și învățare, printre care:

✅ Cursul și materialele didactice disponibile pe platforma Moodle;

✅ Site-uri web și documentația oficială a instrumentelor studiate;

✅ Proiecte și repository-uri realizate de studenții din anii precedenți, utilizate ca exemple de organizare și prezentare;

✅ Tutoriale și ghiduri practice disponibile online.

Pe baza informațiilor studiate, au fost realizate documente teoretice, au fost analizate funcționalitățile IntelliJ IDEA și au fost exersate operațiile de bază din Git și GitHub.

## Structura repository-ului

✅ Documentatie-Teoretica – analiza aplicației IntelliJ IDEA și cerințele și specificațiile tehnice.

✅ Git – documentația privind instalarea, configurarea și utilizarea comenzilor Git.

✅ GitHub – documentația privind crearea, conectarea și publicarea unui repository.

✅ Imagini – capturi de ecran și imagini care ilustrează etapele realizării studiului.

## Instrumente și resurse utilizate

✅ Moodle – pentru consultarea cursului și a materialelor didactice;

✅ IntelliJ IDEA – pentru familiarizarea cu mediul de dezvoltare;

✅ Git – pentru gestionarea versiunilor și a modificărilor;

✅ GitHub – pentru publicarea și organizarea repository-ului;

✅ Microsoft Word – pentru redactarea documentației;

✅ Documentație oficială, site-uri web și proiecte ale studenților din anii precedenți – pentru documentare și exemple.

## Obiectivele studiului

✅ Înțelegerea conceptelor teoretice prezentate în cadrul cursului;

✅ Familiarizarea cu aplicația IntelliJ IDEA;

✅ Învățarea comenzilor de bază Git;

✅ Crearea și gestionarea unui repository local;

✅ Conectarea repository-ului local la GitHub;

✅ Publicarea documentației și a materialelor realizate;

✅ Aplicarea practică a cunoștințelor dobândite pe parcursul studiului individual.

## Concluzie

Prin realizarea acestui studiu individual am consolidat cunoștințele dobândite în cadrul cursului, am utilizat diferite surse de documentare și am acumulat experiență practică în organizarea documentelor, utilizarea Git și publicarea proiectelor pe GitHub.
